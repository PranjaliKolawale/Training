# Training

###Linux Commands (1.Basic Linux Commands 2.File and Directory Management)
MAN COMMAND_NAME: The man command stands for Manual. It is used to display the manual or documentation of Linux Commands, explaining how they work, their option and their usage.
-h(human readable): Displays file sizes in easy-to-read format.
-a(All): Displays all file files, including hidden files.

1. cd - Used to change or navigate between directories.
2. ls - Lists files and directories in the current directory.
3. mkdir - Creates new directory.
4. rmdir - Removes an empty directory.
5. touch - Creates a new empty file or updates its timestamps.
6. pwd - Displays the current working directory path.
7. echo - Displays text or variables in the terminal.
8. cat - Displays the content of the file.
9. clear - Clear the terminal screen.
10. exit - Close the terminal session.
11. whoami - Displays the current logged-in username.
12. date - Displays the current system date and time.
13. cal - Displays the Calender.
14. history - Displays previously executed commands.
15. cp - Copies files and directories.
16. file - Identifies type of file.
17. find - Searches for files and directories.
18. ln - Creates links between files.
19. locate - Quickly searches for files by name.
20. nano - Opens a simple terminal-based text editor.

###Git & Github Commands
1.Basic Git Commands
git --version: Displays the installed Git versions.
git config: Configures git username, email and other settings.
git init: Initializes a new Git repository.
git status: Displays a current status of the working directory.
git add: Adds files to staging area.
git commit: Saves stagged changes to the local repository.
git log: Displays the commit history.
git diff: Shows changes made to files.
