## Linux Commands 
### A.Basic Linux Commands & File and Directory Management
1. cd - Used to change or navigate between directories.
2. ls - Lists files and directories in the current directory.
3. mkdir - Creates new directory.
4. rmdir - Removes an empty directory.
5. touch - Creates a new empty file or updates its timestamps.
6. rm - Removes files or directories.
7. cp - Copy filesor directories.
8. mv - Move or rename files.
9. ln - Create links. *
10. tree - Show directory structure.
11. pwd - Displays the current working directory path.

### B.Pipes and Redirection

### C. File Reading & Editing Commands
12. cat - Display the file content.
13. nano - Write and Edit the file.
14. vim - Write and Edit the file.
15. head - Displays beginning of a file(10 lines).
16. tail - Displays end of a file(10 lines).
17. less - Read files interactively.
18. more - Read files page by page.
19. echo - Displays text or variables in the terminal.
20. clear - Clear the terminal screen.
21. exit - Close the terminal session.

### D. Searching and Locating
22. find - Searches for files and directories.
23. locate - Quickly searches for files by name.
24. grep - Search for text patterns.

### E. Text Processing *
25. sed - Replace or modify text patterns.
26. awk - Process and analyze text.
27. sort - Sort file content.
28. cut - Extract sections of text.
29. diff - Compares two files.
30. tee - Output to terminal and file.

### F. Compression and Extraction
31. zip - Compress files into ZIP archives. (zip archive_name.zip file_name)
32. unzip - Extract ZIP archives. (unzip filename.zip)
33. tar - Create and extract archives. (tar -cvf name.tar file_name - Creating| tar -xvf filename.tar - Extracting)

### G. Permission and Ownership
34. sudo -	Run command as administrator.
35. chmod - Change file permissions.
36. chown - Change file ownership.

### H. User Management
37. su - Switch user account.
38. whoami - Show current user.
39. useradd - Creates new user.
40. userdel - Delete user account.
41. passwd - Set or change password.

### I. System Information and Disk management
42. df - Show disk space usage.
43. du - Show file and directory disk usage.
44. uname - Show kernel information.
45. hostname - Show or set hostname.
46. shutdown - Shut down or restart system.

### J. Networking and file transfer.
47. ping - Test network connectivity
48. wget - Download files from the web.
49. curl - transfer data via URL.
50. scp - Copy files over SSH.(scp source destination)
51. rsync - Synchronize files between locations. (rsync -av source destination)
52. ip - Manage network settings.
53. netstat - Show network connections.
54. traceroute - Trace network packet path. (traceroute hostname/IP)
55. nslookup - Query DNS records. (nslookup hostname/IP)
56. dig - Detailed DNS lookup. (dig [options] domain [record_type]) (example: dig google.com MX)

### K. Package management
57. apt - Manage packages on ubuntu and debian.
58. dnf - Manage packages on Fedora and RHEL-based distributions.

### L. General terminal utilities
59. history - Show command history.
60. man - Show command manual.
61. alias - Create command shortcut. (alias alias_name='command')
62. unalias - Remove command shortcut. (unalias alias_name)
63. cal - Display calender.
