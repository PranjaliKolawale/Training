## Git & Github Commands

### A.Basic Git Commands
1. git --version: Displays the installed Git versions.
2. git config: Configures git username, email and other settings.
3. git init: Initializes a new Git repository.
4. git status: Displays a current status of the working directory.
5. git add: Adds files to staging area.
6. git commit: Saves stagged changes to the local repository.
7. git log: Displays the commit history.
8. git diff: Shows changes made to files.

### B. Github repository Commands
9. git clone: Copies a remote repository to your local computer.
10. git remote: Manage connections to remote repositories.
11. git remote -v: Displays remote repository URLs.
12. git push: Uploads local commits to a remote repository.
13. git pull: Downloads and integrates changes from a remote repository.
14. git fetch: Downloads changes from a remote repository without merging them.

### C. Branch Commands
15. git branch: Displays available branch.
16. git branch branch_name: Creates a new branch.
17. git checkout branch_name: Switches to another branch.
18. git switch branch_name: Switches to another branch.
19. git merge: Combines changes from one branch into another.
20. git branch -d branch_name: Deletes a local branch.

### D. Undo and Reset Commands
21. git restore filename: Discards unstaged changes in a file.
22. git reset: Unstages changes or moves the current branch pointer.
23. git revert: Creates a new commit that reverses an earlier commit.
24. git stash: Temporarily saves uncommitted changes.
25. git stash pop: Restores the most recently stashed changes.
